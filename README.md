## 🗂️ `cat proposito.txt`

Rodo minha própria **fábrica de software indie**: uma plataforma interna completa —
decisões documentadas, catálogo de serviços, observabilidade e infra reproduzível —
aplicada a projetos de um único desenvolvedor, **local-first**.
<br/><sub>I run my own **indie software factory** — documented decisions, a service catalog, observability and reproducible infra, applied to one-person projects, local-first.</sub>

> *"A fábrica produz software; a infraestrutura de cada produto é decidida pelo próprio produto."*
> **— ADR-0007**, a regra que governa as demais
>
> <sub>*"The factory produces software; each product's infrastructure is decided by the product itself."*</sub>

<summary><b>🔍 bônus — como organizo meus projetos</b> <sub>/ how I organize projects</sub></summary>
<br/>

Classificação por **propósito**, não por linguagem — linguagem é o atributo menos estável de um projeto.
<br/><sub>Classified by purpose, not language — language is a project's least stable attribute.</sub>

| pasta | critério de admissão |
|---|---|
| `apps/` | Software que roda para alguém — README, docs, testes automatizados, CI. |
| `tools/` | Utilitários pessoais — README e `.gitignore` bastam. |
| `_labs/` | Experimentos e PoCs. Descartável por definição. |
| `_platform/` | A fábrica em si — decisões, padrões, scripts. |
| `archive/` | Concluído. Não evolui mais. |

**Decisões recentes (ADRs):**
- **0007** — Separar software factory de deployment *(a regra que governa as demais)*
- **0013** — SOPS + age para secrets locais
- **0015** — Frontend padrão da fábrica: FastAPI + Jinja2 + htmx + Alpine

<sub>+ 13 outras decisões registradas — arquitetura documentada como parte do processo, não depois dele.</sub>
